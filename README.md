# Білім-инновация лицейлеріндегі академиялық және тұлғалық даму

Магистрлік деңгейдегі HTML-презентация (26 слайд, толығымен қазақ тілінде).

## Ашу
`presentation/index.html` файлын кез келген браузерде ашыңыз (интернет тек қаріп үшін қажет, онсыз да жұмыс істейді).

| Перне | Әрекет |
|---|---|
| → / Space / PageDown | келесі слайд |
| ← / PageUp | алдыңғы слайд |
| Home / End | бірінші / соңғы слайд |
| F | толық экран |
| P | PDF-ке басып шығару (әр слайд — жеке бет) |

## Мазмұны
Өзектілік және қайшылықтар · ғылыми аппарат · ғылыми жаңалығы · ұғымдар кестесі · теориялық негіздер · БИЛ тарихы (уақыт сызығы + иллюстрация) · БИЛ моделі (хаб-диаграмма) · салыстырмалы кесте (БИЛ / НЗМ / жалпы мектеп) · академиялық даму пирамидасы және Циммерман циклі · тұлғалық даму компоненттері · кіріктірілген педагогикалық модель · Венн диаграммасы және педагогикалық шарттар · диагностика әдістемелері · эксперимент дизайны · нәтижелер (бағаналы, радар, шашырау, дөңгелек, сызықтық графиктер) · статистикалық кесте (t, p, Cohen d) · SWOT · тиімді тәжірибелер · ұсыныстар · қорытынды · әдебиеттер.

## Маңызды
* `[Аты-жөні]`, `[ЖОО атауы]`, `[Қала]` сияқты орындарды өз деректеріңізбен ауыстырыңыз.
* 17–20 слайдтардағы сандық нәтижелер — **пилоттық зерттеудің үлгі деректері**. Оларды өз экспериментіңіздің нақты нәтижелерімен ауыстырыңыз: деректер `index.html` соңындағы `/* ---- деректер ---- */` бөлімінде, ал 19-слайдтағы кесте HTML ішінде.
